# Esports Individuals

Materials del mòdul d'Esports Individuals del CFGS d'Ensenyament i Animació Socioesportiva (EAS).

## Estructura

```
index.html                             Portada del mòdul (entrada a tots els materials)
ensenyar-a-nedar/index.html            Ensenyar a nedar: tècnica dels quatre estils, etapes, jocs i seguretat
habilitats-medi-terrestre/index.html   Habilitats al medi terrestre: habilitats motrius bàsiques, esports individuals i jocs
fitxer-de-jocs/index.html              Fitxer de jocs: calaix A (aigua) i calaix T (terra)
```

Cada material és una pàgina HTML autònoma dins la seva carpeta, sense dependències ni compilació. Per veure-ho, obre `index.html` al navegador.

Enllaços directes al fitxer de jocs:

- `fitxer-de-jocs/index.html#aigua` obre el calaix d'aigua.
- `fitxer-de-jocs/index.html#terra` obre el calaix de terra.

## Afegir un material nou

1. Crea una carpeta nova (per exemple `nou-material/`) amb el seu `index.html`.
2. Afegeix-hi un enllaç de tornada a la portada: `<a href="../index.html">← Esports Individuals</a>`.
3. Afegeix una tarja nova a `index.html`, dins de `<div class="cards">`.
